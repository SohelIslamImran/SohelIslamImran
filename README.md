# Sohel Islam Imran — Folio

Personal site: an optical light table. **TanStack Start**, React 19, **Bun**.

```bash
bun install
bun run dev
```

Public pages (`/`, `/work`, `/story`, `/field-notes`, `/resume`, `/links`) are prerendered to static HTML. Navigation preloads on hover and warms the rest of the public routes while the page is idle.

Appearance and accent **gels** live in the header (and the phone menu). Studio is owner-gated.
