## Evidence language

- **Verified:** a direct authored artifact, official record, or first-party profile states the fact. This does not make a self-evaluation objective.
- **Corroborated:** two or more sources agree, usually including an authored artifact or restricted business record.
- **Strong inference:** the evidence supports the conclusion, but no source states it directly.
- **Unverified:** missing, conflicting, stale, or supported only by a weak signal.
