# Kuno

## Overview

Kuno is a professional-development platform that uses guided peer conversations to help people practice and apply workplace capabilities. Its public product describes diagnostics, pathways, peer matching, structured sessions, and progress feedback for companies, education providers, and communities.

Public sources: [Kuno company site](https://www.kuno-ai.com/), [Kuno LinkedIn](https://www.linkedin.com/company/kuno-ai).

## Problem

Kuno aims to turn professional learning into applied capability. The product needs to coordinate personal learning paths, peer matching, guided conversations, company program administration, and evidence of progress without losing clear access boundaries or a dependable release path.

## Solution

Public profiles and the portfolio describe a TypeScript product with React and TanStack interfaces, Bun and Elysia services, Drizzle, PostgreSQL, Redis, and cloud infrastructure. Restricted repository evidence confirms work across web, mobile, API, data, background processing, localization, testing, operations, and deployment.

## Challenges

- Keeping role-aware user journeys consistent across mobile, learner, company, and administration experiences.
- Applying authorization across a workflow rather than relying on a single interface gate.
- Coordinating product releases across application, infrastructure, and operator tooling.
- Supporting bilingual and AI-assisted experiences while minimizing private-data exposure.
